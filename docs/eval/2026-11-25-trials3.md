## What changed since 2026-11-23

Run because the browser layer changed: Witness now waits for the network to go quiet after each page load, and checks the backend first. The [previous eval](2026-11-23-trials3.md) was on older code.

- **Verdicts are the same:** every case scored as before. All 24 bug verdicts were read by hand, and each names the planted bug.
- **Replays are slower:** mean 2.0s, up from 1.4s. The readiness wait adds about half a second per page load: replays that only open the page went from about 0.2s to 0.7s.
- **Agent runs took about 3s longer** (41s, up from 38s). The readiness wait is a likely cause, but model speed varies too.

Not covered: the Feature Map and the scenario map. The eval runs the Driver without a map, so it says nothing about whether they help.
